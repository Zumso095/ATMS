# Health fix — 2026-09-29

Изменены только HealthAttributeSet.cpp и HealthAttributeSet.h.

- Death при выполнении эффекта вызывается только при переходе положительного HP к нулю.

- Оружие, Blueprint, настройки и мана не изменялись.
